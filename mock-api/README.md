# Practice API

Start the local API from the project root:

```bash
yarn api
```

The server runs on port `3001` and exposes:

- `GET http://localhost:3001/users`
- `GET http://localhost:3001/users/u1`
- `POST http://localhost:3001/users`
- `PUT/PATCH/DELETE http://localhost:3001/users/:id`

Keep this server running in one terminal and run the app in another terminal.
