# Exercise 01 — User directory

## Context

You joined an existing project with a small user-directory component. Read the code before changing it and explain what the component currently renders.

## Requirement

The product owner only wants active users in this view.

1. Show active users only.
2. Sort them alphabetically by name.
3. Update the subtitle so it says `4 active users`.
4. Do not modify the original `users` array.

Use the smallest clear solution. Do not add a library or extract new files.

## While coding

Explain:

- where you would derive the visible users and why;
- why mutating the original array could be a problem;
- which operations create a new array;
- what causes this component to render.

Stop after this requirement. The interviewer will provide follow-ups separately.
